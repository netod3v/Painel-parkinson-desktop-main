# Documentação (TCC) - Painel Parkinson Desktop

Este repositório é dedicado exclusivamente ao armazenamento do **documento escrito e código-fonte em LaTeX** da monografia do nosso Trabalho de Conclusão de Curso (TCC).

O projeto documentado aqui aborda o desenvolvimento e a migração do sistema **Painel Parkinson Desktop** para a arquitetura local com Electron.js. Trata-se de um Sistema de Apoio à Decisão Clínica (SADC) focado na avaliação e monitorização motora da Doença de Parkinson, utilizando a escala clínica padrão-ouro (MDS-UPDRS).

## 📁 Sobre este repositório
Aqui encontram-se todos os arquivos de texto (`.tex`), bibliografia (`.bib`) e imagens utilizadas na estruturação do documento final. A separação deste repositório garante a organização e o controle de versões (histórico de alterações) focado unicamente na redação acadêmica, prevenindo perdas de informação.
